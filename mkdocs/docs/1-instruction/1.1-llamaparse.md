# Tutorial: LlamaParse setup

## Add llamaparse to requirements.txt:   
```

llama-index==0.10.*
python-dotenv==1.*
chromadb
llama-index-vector-stores-chroma
llamaparse

```
# create a virtual environment (only if you never created one before)
```
python -m venv venv
```

## activate the virtual environment 
```
#for MAC
source venv/bin/activate

#for Windows
venv\Scripts\activate
```

## install the dependencies
```
pip install -r requirements.txt
```

## Add LLAMA_CLOUD_API_KEY to .env
```
OPENAI_API_KEY=

LLAMA_CLOUD_API_KEY=
```


## Create 3 storage directories
```
 storage_origin
 storage_parse
 storage_index
 ```

## Create tutorial directory
```
tutorial/parse_html.py
```
